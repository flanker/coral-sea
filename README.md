# 珊瑚海 · 迷雾中的航母对决

中文桌面端交互历史海图。三章时间线、三种视角、情报延迟与误报、舰队记录、来源与历史解释。

已完成4轮迭代；最终独立评审 **8.8/10**，全部必需项通过。见 [最终评审](docs/CRITIC-4.md) 与 [验收记录](docs/VALIDATION.md)。

## 在线访问

https://flanker.github.io/coral-sea/ 。推送到 `main` 后由 GitHub Actions 自动构建并部署到 GitHub Pages（见 `.github/workflows/deploy.yml`）。

## 本地运行

需要 Node.js 22。首次运行 `npm install`，然后 `npm run dev -- --port 5173`，访问 http://127.0.0.1:5173 。

- `npm run build`：类型检查并构建静态页面。
- `npm run preview`：预览构建结果。
- `npm test`：时间、观察者、情报和历史状态的核心测试。
- `npm run check:data`：数据引用、时序、坐标、修正链和核心事件覆盖校验。
- `npm run coverage`：重新生成逐日、逐部队和逐事件来源表。
- `npm run test:browser`：本地服务开启后，用系统 Google Chrome 执行25组浏览器检查并保存截图。

海岸线随应用打包，来自 world-atlas / Natural Earth 公有领域数据。无需地图密钥。在线字体不可用时采用本地字体回退，核心功能不依赖字体网络请求。

## 操作

顶部切换章节、观察视角；底部按日期和时间探索，可播放、暂停、调整速度与时间尺度。地图可平移缩放，点击部队或事件查看详情。选中部队可跟随，手动拖动地图退出跟随。空格播放／暂停，左右方向键跳转，Esc 关闭详情。引导回放在关键记录处自动暂停。

上帝视角可用未来事件导航，地图仍只显示当前态势；阵营视角只展示已知记录。向前按钮计算下一次允许呈现的记录时间，到达该刻后才显示标题与内容。原始报告在纠正后仍保留在日志中。地址包含时间、视角和所选事件，可复制分享或刷新恢复。

## 建议体验路径

1. 打开[5月7日10:30，美军视角](https://flanker.github.io/coral-sea/?time=1942-05-07T00%3A30%3A00Z&view=us)，在同一时刻切换日军和上帝视角，比较双方各自误认的目标。
2. 打开[5月7日10:59](https://flanker.github.io/coral-sea/?time=1942-05-07T00%3A59%3A00Z&view=us)，勾选引导回放并播放，观察11:00的报告纠正；继续到11:23，出击方向随新报告调整。
3. 打开[5月8日12:00，列克星敦号损管](https://flanker.github.io/coral-sea/?time=1942-05-08T02%3A00%3A00Z&view=god&event=08-explosion)，切换美军视角。舰上已发生的爆炸，要等失控通知到达指挥部后才进入该视角。

## 数据与维护

- `src/data/events.ts`：历史事件及分别撰写的阵营账户。E() 参数对应 ID、时间、精度、阵营、类型、标题、叙述、地点、单位、来源、文献位置与可见账户。
- `src/data/contacts.ts`：独立接触报告、接收时间和修正关系。
- `src/data/units.ts`：部队、记录位置及区分实际发生／获知时刻的状态变化。
- `src/data/sources.ts`：来源目录与限制。
- `src/engine.ts`：按观察者和时间重建状态的纯函数，地图和所有内容入口共用。

`own: true` 仅适用于可在指挥部或明确标注的阵营层级获知的内容。不能用它给本方指挥部即时提供远方机组或分遣部队的观察。需要显式接收时刻时，填写独立账户。内容不得以战时战果直接替代事后确认结果。

## 研究边界

当前包含121条事件、7条情报接触和8支部队。资料以美军战时叙述、日方参战参谋的战后证词、通信调查和现代官方综述为主；日方原始电报与航海资料仍有覆盖缺口。具体争议与采取的保守处理见 `docs/RESEARCH.md`。舰位不是连续实时轨迹，示意范围也不是实测搜索计划。

实现任务与验收标准见 `docs/GOAL.md`；迭代进度与独立评审记录见 `docs/PROGRESS.md`。

验证证据见 [VALIDATION.md](docs/VALIDATION.md)、[来源覆盖表](docs/COVERAGE.md)。源文时钟转换规则在 `src/time.ts`，未知时区与近似节点在卡片和研究说明中披露。

报告版本使用固定ID：首报沿用事件ID，后续版本为 `事件ID~1` 等；不要用“当前是否为最新”重新编号。每个账户独立填写时间精度，编排节点不写成原文时标。搜索方向、角度与已知范围由事件的 `searchPlan` 字段提供。

出击方向可以通过 `route.revisions` 引用新的报告事件。状态引擎仅在该报告对当前观察者可见后采用其报告位置，传给地图的数据不包含未来修订。7日两支美军攻击群以原报为初始目标，11:23收到新报告后调整。
